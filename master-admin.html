ℹ️ Password disimpan aman di server. Perubahan langsung berlaku untuk login berikutnya di semua perangkat. Tidak ada yang bisa melihat password — hanya bisa direset (lihat di bawah).
❓ Lupa password? Cara reset
Kalau lupa PIN Master Admin / Admin, reset lewat Google Apps Script (butuh akun Google pemilik script):
  1. Buka project Apps Script situs ini (script.google.com → project Little Star).
  2. Klik ⚙️ Project Settings.
  3. Scroll ke Script Properties.
  4. Hapus baris MASTER_PIN dan/atau ADMIN_PIN (klik ikon hapus), lalu Save.
  5. PIN otomatis kembali ke default: Master Admin 5758, Admin 17081945. Login pakai itu, lalu ganti lagi di halaman ini.
Tidak perlu ubah kode atau redeploy. Kalau bingung, hubungi yang mengelola Apps Script.
